# Architectural Decision Records (ADRs)

| ID | Decision | Reason | Status |
| :--- | :--- | :--- | :--- |
| **ADR-001** | **Keep detached per-project workers** | Provides process crash isolation and failure containment without requiring heavyweight microservices or external service managers. Workers run as independent OS processes. | **Locked** |
| **ADR-002** | **Maintain one authoritative `EngineController` with `engine.db` holding lifecycle authority** | Eliminates split-brain lifecycle ownership (the two-Supervisor defect) and PID-only fragility. `engine.db` tracks authoritative project, worker, and operation states; the reconciler becomes the sole entity declaring process loss. | **Locked** |
| **ADR-003** | **Keep stdlib HTTP + REST + SSE (no FastAPI or WebSockets)** | Framework rewrites do not fix the root failure modes (lifecycle races, storage mutations). Standard library HTTP with clean REST contracts and bounded SSE streams keeps deployment dependency-light and maintainable. | **Locked** |
| **ADR-004** | **Make GET endpoints strictly read-only to prevent storage mutation** | Eliminates critical defect N1/N2 where GET calls triggered auto-archiving, history consolidation, WAL truncate checkpoints, and phantom project metadata synthesis. Ordinary reads must never write to disk or DB. | **Locked** |
| **ADR-005** | **Maintain permanent current project storage with legacy compatibility views** | Physical directory moves (`current/` to `last_run/` or `history/`) on process stop cause race conditions and lost states on resume. Projects live permanently in `data/projects/<slug>/`; legacy tiers become virtualized read compatibility views. | **Locked** |
| **ADR-006** | **Use Git as content/version store, paired with a Manifest** | Eliminates heavy in-memory text caches and baseline directories. Shadow Git handles exact content/version diffs, while a lightweight manifest tracks fast file state fingerprints (`before != after`). | **Locked** |
| **ADR-007** | **Make `event_id` the canonical identity (burst numbers are display-only)** | Burst numbers are non-unique across restarts and sessions. A stable, globally unique `event_id` ensures durable cross-referencing across SQLite, Shadow Git commits, and AI cache tables. | **Locked** |
| **ADR-008** | **Implement non-destructive rollback using workspace revision statuses** | Destructive commands (`git clean -fd`) can destroy uncommitted work. Rollback restores target anchor state while preserving forward history by marking affected events `rolled_back`/`superseded` and emitting an auditable `ROLLBACK` event. | **Locked** |
| **ADR-009** | **Move AI entirely to the controller (durable jobs), ensuring workers do not hold API keys** | Decouples the capture pipeline from external API rate limits, network latency, and model failures. Workers produce context references; the controller schedules durable background jobs without leaking credentials into worker environments. | **Locked** |
| **ADR-010** | **Eliminate timer-based bundling, runtime consolidation, and GET-triggered archiving** | Replaces fragile `threading.Timer` instances with a condition-variable `BurstAssembler`. Disables runtime consolidation and read-triggered storage mutations, preventing SQLite contention and burst sealing stalls. | **Locked** |
| **ADR-011** | **Maintain per-project SQLite database with dedicated single `ProjectWriter`** | Prevents concurrent thread contention and transaction corruption on `session.db`. All write operations are serialized through a single writer thread queue, while readers use read-only SQLite connections. | **Locked** |
| **ADR-012** | **Eliminate process substring matching in favor of exact multi-attribute identity** | Prevents process reapers from accidentally terminating collateral processes that share substring names. Process verification mandates matching PID, process creation timestamp, executable path, exact `worker_id`, and canonical project path. | **Locked** |
| **ADR-013** | **Disable automatic repository push by default** | Auto-pushing to primary repositories can inadvertently leak credentials or push broken states. Remote push is converted to an opt-in, branch-allowlisted, credential-isolated controller background task. | **Locked** |
| **ADR-014** | **Enforce local API security hardening (Host/Origin/Token)** | Prevents CSRF and arbitrary origin attacks against localhost ports. Requires loopback token authentication for state mutations, a strict Host header allowlist, and CORS origin validation. | **Locked** |
| **ADR-015** | **Standardize persisted timestamps on UTC ISO 8601** | Eliminates time-zone drift bugs where local timestamps (e.g., IST `+05:30`) were parsed as UTC `Z`, skewing heartbeat checks and timeout calculations. Local formatting is confined strictly to the UI layer. | **Locked** |
| **ADR-016** | **Production Wiring of `BurstAssembler`** | Condition-variable sliding window replacing `EventBundler` to prevent Win32 DWORD timer overflows, thread leaks, and timestamp race conditions. | **Locked** |
| **ADR-017** | **Multi-Attribute Worker Identity Propagation** | Enforcing exact `--worker-id` UUID CLI propagation and 6-point verification in Supervisor to prevent collateral process termination and PID reuse false adoptions. | **Locked** |
| **ADR-018** | **Dynamic SQL Projection for Legacy V1 Read-Only Endpoints** | Read compatibility on GET routes achieved via dynamic column inspection and SQL aliasing (`('ev_' || e.id) AS event_id`) without executing DDL/DML mutations or breaking read-only invariants. | **Locked** |
| **ADR-019** | **Deterministic ChangeSet Consistency** | Guaranteeing that every burst creating a Git commit persists matching effective file entries in `patches` and SQLite, ensuring that Git changed files, SQLite records, API responses, and UI renders remain 100% consistent. | **Locked** |
| **ADR-020** | **Remediation of Manager Audit Ledger & Wiring of Modern Stack** | Wire the modern `LifecycleController`, `ProjectWriter`, and non-destructive rollback directly into production routes while removing legacy destructive fallbacks and un-checkpointed WAL directory copies. | **Locked** |
